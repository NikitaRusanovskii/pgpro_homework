Как ориентироваться по данному репозиторию?

## Внимание, если вы видите эту надпись, это инициализирующий коммит. Код расширений и скриптов может не собираться или не работать. Это связано с группировкой всех материалов. Пути в файлах ещё не обновлены!

*Auto/* - папка со скриптами, которые я написал для автоматизации процессов.
        Для запуска скриптов рекомендую создать виртуальное окружение, установить
        зависимость из файла requirements.txt (если таковые имеются):

        ```bash
            cd Auto/
            python -m venv env
            pip install -r requirements.txt
            chmod +x env/bin/activate
            source env/bin/activate
        ```
        Данная последовательность команд позволит вам запускать скрипты, лежащие в
        папке Auto.
        python и pip должны быть установлены в $PATH и содержать пути, ведущие к
        соответствующим программам!

        ```bash
            python <script>.py [options...]...
        ```

*Ext/* - папка, содержащая учебные расширения.

*Reports/{stage}/{task}* - каталог, в который я помещаю отчёты по задачам.
    Stage - номер этапа.
    Task - номер задания.

В процессе выполнения заданий я также использую папки *Build/*, куда собираются различные
версии Postgres, и *Data/*, где содержатся каталоги для кластеров.
Если для проверки задания необходимо воспользоваться определённой версией Postgres или же
специально настроенным кластером, я обязательно приложу README-файл в папку с таким заданием.
